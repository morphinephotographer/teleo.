# Security boundaries

Local scripts are sensitive. Browser scripts/revisions/recovery journal/position stay in origin-local stores; Apple scripts go to device-local SwiftData and, only after signed capability setup, private Apple CloudKit. No text, title, file, language content or folder name is part of either remote protocol. No analytics, user accounts or embedded recording. An active browser profile or unlocked native app can access its own library; device compromise is out of scope.

Browser trust: HTTPS/WSS is mandatory in production. Host and invitation capabilities use independent 32-byte crypto random values, only hashes are retained in durable storage. Capability travels in invitation fragment and first authenticated socket frame, not URL query/path. Room creation responses are no-store. Use no analytics, referrer disclosure or third-party QR service. Session state/revocation/TTL/replay IDs live in Durable Object storage; socket roles/rate counters in serialized attachments. Hibernation eviction integration tests exercise production handler code. Concurrency gates serialize authentication and authorization mutations, so simultaneous invite uses cannot both enroll. Unknown/oversized/invalid-role/content-bearing commands close the offending socket. Unauthorized socket closure does not revoke the host. Authenticated peer loss revokes the whole session. One-use invite expiry is independently tested with real elapsed time.

Origin allowlist, 10 room creations/minute per provider-supplied IP (hashed into rate-object identity), socket cap, 20 frames/sec, strict allowlist, finite numeric ranges, bounded request ledger, outstanding-ACK validation, expiration alarms and heartbeats limit abuse. Protect production routes with Cloudflare edge rate rules/WAF as well: application rate limits alone do not prevent distributed resource exhaustion. Local creation limits share a fallback bucket when provider IP is absent. No raw capability logs; Worker observability is disabled by default. Never enable payload logging. Local Wrangler may log routes/public object IDs, but capabilities are not in them. Wrangler telemetry is disabled by npm relay script after project setup.

Native trust: Bonjour is untrusted discovery. Possession of an out-of-band 256-bit invitation PSK authenticates the encrypted TLS peer; host approval authorizes commands. Session UUID, TTL and one-use admission bind control to the explicit host session. The transferred invite must remain private. A six-digit code is never used as sole authentication. TLS 1.2 PSK is used because Apple documents PSK limitations with newer Network/QUIC APIs. Independent security review and physical-device verification are release gates. Network messages use bounded framing, strict command fields and replay IDs. No plaintext or certificate-validation bypass fallback exists. Revocation closes the connection and invalidates the gate.

Known limitations: no seamless reconnect, no automatic conflict-free text merge, no advanced pairing transcript UX/QR on native, no third-party penetration test, physical accessory and public WSS verification pending. A relay operator can see control commands and timing; relay security is transport TLS plus application authorization, not end-to-end encrypted browser command payloads. Script content never enters that trust boundary.

Imports are data only, never executed. JSON versions/ranges/size are validated, text is rendered by React/native attributed text, exports use sanitized download names. Existing script IDs are not trusted to overwrite the library on import. Tombstones are never automatically purged, avoiding disconnected resurrection through cleanup; concurrent native updates/deletions still need physical CloudKit conflict testing.
