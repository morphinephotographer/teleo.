# Публикация исправления верхней панели iPad

Владелец разрешил публикацию сообщением «опубликуй» после локального аудита.

- Production: https://teleo.cc/studio, Worker `teleo-web`.
- Опубликованный исходный коммит: `316af919b38d498606ebd292712c6327a508e3f7`.
- Production-версия: `8c8c38ff-9b88-443d-a446-35ca8b7fb166`, подтверждено 100% трафика.
- Время выпуска по Киеву: 1 ноября 2026, 00:48:19.
- Проверенная staging-версия: `da24478e-e036-4386-be8a-1f2a0a418da1`.
- Предыдущая production-версия для отката: `98de5ba3-4bdf-47ab-a30e-776d1b6a0bbb`, исходный коммит `fc823d8abc5a3915b98c875e839d3641d14dced2`.

Для Studio шире 600 CSS px верхняя панель и оконная область чтения учитывают `env(safe-area-inset-top)`. Изменение сохраняет место под системной строкой iPadOS при повороте устройства. Публикация выполнена штатным интерактивным `npm run deploy:production` из чистого коммита после проверки staging. Настройки доменов, хранилища, протокол и миграции не менялись.

## Проверки опубликованной сборки

| Проверка | Staging | Production |
| --- | ---: | ---: |
| WebKit: 3 языка × 2 темы × 4 размера iPad | 24/24 | 24/24 |
| Chromium/WebKit: Open last, клавиши standard/R400/custom, настройки, импорт TXT/JSON | 12/12 | 12/12 |
| Маршруты, защитные заголовки и Origin/API | 2/2 | 2/2 |
| Совпадение SHA-256 HTML, CSS, JS и service worker с локальной сборкой | 4/4 | 4/4 |

Production-проверки дополнительно подтвердили X-Teleo-Commit и X-Teleo-Deployment на ресурсах, корректный HTTPS и перенаправление www с сохранением пути и query. Cloudflare deployment readback подтвердил новую версию на 100% трафика.

Для WebKit-проверок использованы отдельные профили с локальными тестовыми библиотеками; реальный опубликованный CSS загружен с сервера, а значение системного отступа смоделировано как 24 px. Проверены границы элементов header, отсутствие их пересечений, положение области чтения и отсутствие pageerror. Физический iPad и реальная строка состояния iPadOS не проверялись.

Локальные проверки и известные устаревшие браузерные сценарии описаны в [аудите](TELEO_LOCAL_AUDIT_2026-11-01.md): полный выбранный набор не является зелёным (132/210, 78 сбоев старых проверок); эти сценарии не исправлялись и не выдаются за успешные. Проверки выше выполнены отдельно против действующих публичных сборок.

Локальные артефакты: `test-results/ipad-publication/teleo.cc/assets.json`, снимки iPad в том же каталоге и `test-results/ipad-publication/production-deployments.txt`. Для отката сохранена предыдущая версия; откат не выполнялся. Этот отчёт записан после публикации и не меняет опубликованный исходный коммит.
